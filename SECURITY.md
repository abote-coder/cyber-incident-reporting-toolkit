# Security Policy

## Handling data in this repository

- This repository must contain **only fictional or anonymised** examples.
- **Never commit** passwords, API keys, tokens, private keys, personal information or real incident evidence.
- Use the `.gitignore` file provided and enable GitHub **secret scanning** and **push protection**.
- Use initials or IDs instead of full names in examples.

## Reporting a problem

If you find sensitive information accidentally committed, do not just delete the file. Tell the repository owner immediately, rotate any exposed credentials and remove the data from the Git history.
